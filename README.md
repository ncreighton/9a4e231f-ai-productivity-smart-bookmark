# AI Productivity Smart Bookmark Manager Extension

Chrome extension that uses AI to auto-categorise, tag, and surface relevant bookmarks based on what you're working on. Features semantic search across 1000+ bookmarks, smart collections, duplicate detection, and one-click export to Notion or Obsidian. Productivity tool for researchers and power users.

## Installation

### Chrome
1. Download and extract the ZIP
2. Go to `chrome://extensions/`
3. Enable "Developer mode"
4. Click "Load unpacked" and select the extracted folder

### Firefox
1. Download the Firefox version
2. Go to `about:debugging`
3. Click "Load Temporary Add-on"
